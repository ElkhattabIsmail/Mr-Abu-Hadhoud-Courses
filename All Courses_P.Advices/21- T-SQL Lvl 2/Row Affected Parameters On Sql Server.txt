Let's walk through a complete example that demonstrates how SET NOCOUNT ON vs. SET NOCOUNT OFF affects the return value of ExecuteNonQuery() in C#.

🔧 1. SQL Setup
Suppose you have this table:

CREATE TABLE TestTable (
    Id INT PRIMARY KEY,
    Name NVARCHAR(100)

✅ 2. SQL Command with SET NOCOUNT
Case A: SET NOCOUNT ON
sql

-- Stored Procedure or command
SET NOCOUNT ON;

UPDATE TestTable
SET Name = 'Updated'
WHERE Id = 1;
Case B: SET NOCOUNT OFF (default)
sql
Copier
Modifier
SET NOCOUNT OFF;

UPDATE TestTable
SET Name = 'Updated'
WHERE Id = 1;
💻 3. C# Code Example
csharp
Copier
Modifier
using (SqlConnection conn = new SqlConnection("YourConnectionString"))
{
    conn.Open();

    string sql = @"
        SET NOCOUNT OFF;
        UPDATE TestTable SET Name = 'Updated' WHERE Id = 1;
    ";

    using (SqlCommand cmd = new SqlCommand(sql, conn))
    {
        int rowsAffected = cmd.ExecuteNonQuery();
        Console.WriteLine("Rows affected: " + rowsAffected);
    }
}
