Query
The query is:

sql
Copy
WITH EmployeeTreeHierarchy AS (
    -- Anchor member: Select the root of the hierarchy (CEO)
    SELECT EmployeeID, ManagerID, Name, 
           CAST(Name AS VARCHAR(MAX)) AS 'Hierarchy', 
           0 AS Level
    FROM Employees7
    WHERE ManagerID IS NULL

    UNION ALL

    -- Recursive member: Build the hierarchy
    SELECT empTable.EmployeeID, empTable.ManagerID, empTable.Name, 
           CAST(ETH.Hierarchy + '  <-  ' + empTable.Name AS VARCHAR(MAX)), 
           ETH.Level + 1 AS Level
    FROM Employees7 empTable
    INNER JOIN EmployeeTreeHierarchy ETH ON empTable.ManagerID = ETH.EmployeeID
)
-- Final SELECT: Retrieve the hierarchical data
SELECT * FROM EmployeeTreeHierarchy
ORDER BY Hierarchy;

The anchor member initializes the hierarchy with the CEO.

The recursive member builds the hierarchy by joining employees with their managers and appending their names to the Hierarchy path.

The recursion stops when no more employees are found under the current level.
