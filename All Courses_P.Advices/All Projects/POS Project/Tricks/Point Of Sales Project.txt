Point of Sale (POS) System
Project Overview
A Point of Sale (POS) System is a desktop application designed to streamline sales transactions, manage inventory, and track customer purchases in a retail environment. It provides an intuitive interface for cashiers and managers to process sales, generate receipts, and monitor stock levels.

Key Features
Product Management:

Add, update, and delete products (e.g., name, price, quantity, category).

Categorize products (e.g., electronics, clothing, groceries).

Sales Transactions:

Process sales and generate receipts.

Calculate total cost, taxes, and discounts.

Support for multiple payment methods (e.g., cash, credit card).

Inventory Management:

Track stock levels in real-time.

Receive alerts for low stock or out-of-stock items.

Automatically update inventory after sales.

Customer Management:

Add and manage customer details (e.g., name, contact information).

Track customer purchase history.

Reporting:

Generate daily, weekly, and monthly sales reports.

View inventory reports (e.g., stock levels, out-of-stock items).

Analyze revenue and profit margins.

User Authentication:

Login system for different user roles (e.g., cashier, manager).

Restrict access to sensitive features based on user roles.

Receipt Generation:

Print or save receipts for customers.

Include details like product name, quantity, price, and total cost.

public void AddProduct(string name, decimal price, int quantity, string category)
{
    using (SqlConnection connection = new DatabaseHelper().GetConnection())
    {
        string query = "INSERT INTO Products (Name, Price, Quantity, Category) VALUES (@Name, @Price, @Quantity, @Category)";
        SqlCommand command = new SqlCommand(query, connection);
        command.Parameters.AddWithValue("@Name", name);
        command.Parameters.AddWithValue("@Price", price);
        command.Parameters.AddWithValue("@Quantity", quantity);
        command.Parameters.AddWithValue("@Category", category);

        connection.Open();
        command.ExecuteNonQuery();
    }
}
3. Process Sale
csharp
Copy
public void ProcessSale(List<SaleItem> items, string paymentMethod, int cashierID)
{
    using (SqlConnection connection = new DatabaseHelper().GetConnection())
    {
        connection.Open();

        // Insert into Sales table
        string saleQuery = "INSERT INTO Sales (SaleDate, TotalAmount, PaymentMethod, CashierID) VALUES (@SaleDate, @TotalAmount, @PaymentMethod, @CashierID); SELECT SCOPE_IDENTITY();";
        SqlCommand saleCommand = new SqlCommand(saleQuery, connection);
        saleCommand.Parameters.AddWithValue("@SaleDate", DateTime.Now);
        saleCommand.Parameters.AddWithValue("@TotalAmount", items.Sum(item => item.Price * item.Quantity));
        saleCommand.Parameters.AddWithValue("@PaymentMethod", paymentMethod);
        saleCommand.Parameters.AddWithValue("@CashierID", cashierID);

        int saleID = Convert.ToInt32(saleCommand.ExecuteScalar());

        // Insert into SaleDetails table
        foreach (var item in items)
        {
            string detailQuery = "INSERT INTO SaleDetails (SaleID, ProductID, Quantity, Price) VALUES (@SaleID, @ProductID, @Quantity, @Price)";
            SqlCommand detailCommand = new SqlCommand(detailQuery, connection);
            detailCommand.Parameters.AddWithValue("@SaleID", saleID);
            detailCommand.Parameters.AddWithValue("@ProductID", item.ProductID);
            detailCommand.Parameters.AddWithValue("@Quantity", item.Quantity);
            detailCommand.Parameters.AddWithValue("@Price", item.Price);
            detailCommand.ExecuteNonQuery();

            // Update product quantity
            string updateQuery = "UPDATE Products SET Quantity = Quantity - @Quantity WHERE ProductID = @ProductID";
            SqlCommand updateCommand = new SqlCommand(updateQuery, connection);
            updateCommand.Parameters.AddWithValue("@Quantity", item.Quantity);
            updateCommand.Parameters.AddWithValue("@ProductID", item.ProductID);
            updateCommand.ExecuteNonQuery();
        }
    }
}
